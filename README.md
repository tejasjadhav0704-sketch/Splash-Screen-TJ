# Splash Screen TJ App

A modern Android application with a smooth and premium splash screen experience designed using Figma and animated using Lottie.

---

## Features

- Clean UI designed in Figma  
- Smooth splash screen animation using Lottie  
- Simple and fast Android app flow  
- Easy navigation between activities  
- Modern and lightweight design  

---

## Tech Stack

- Android Studio  
- Kotlin / Java  
- Lottie Animation  
- Figma (UI Design)  
- XML Layouts  

---

## Splash Screen

The splash screen is created using:
- Figma design export  
- Lottie JSON animation  
- Android Lottie integration  

It provides a smooth and modern startup experience.
